# Dex++ – Enhanced Script Search

An open-source extension for **Dex Explorer** that enhances its search functionality with two search modes.

### Features
- **Content Search** – Search within the actual contents of every script in the game.
- **Name Search** – Search for scripts by their names, just like the standard Dex search.
- **Lightweight** – Minimal overhead with no unnecessary features or dependencies.
- **Open Source** – Freely available for inspection, modification, and contribution.

Switch between searching script contents and script names depending on what you're looking for. Simple, lightweight, and focused on functionality.
